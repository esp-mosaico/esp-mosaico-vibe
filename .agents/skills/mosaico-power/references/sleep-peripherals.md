# 各模块功耗设置

## 显示：CO5300 OLED

以下是本模组的命令序列；优先通过驱动/BSP 执行，与绘图串行，切换前等待 DMA 完成。

| 模式 | 进入 | 恢复 |
| --- | --- | --- |
| 普通显示调暗 | 页 0 下 `51 xx` 设置面板亮度 | 恢复用户亮度 |
| AOD，保留画面 | `FE 00 → 51 xx → 39`；本模组 20% 使用 `xx=33`，均为十六进制 | `FE 00 → 38`，再恢复用户亮度 |
| 黑屏睡眠 | `28 → 10`：Display OFF、Sleep IN | Sleep OUT `11`，按驱动延时并恢复画面，再 Display ON `29` |

AOD 不保证原有渐变/灰度效果，需检查文字可读性。`28 → 10` 不能保持可见画面；检查驱动是否额外进入 Deep Standby，需要复位才能恢复。
软件 RGB 压暗、面板亮度和 AOD 是不同设置；停止 SPI 传输不会停止 OLED 发光。大面积黑/深色通常比白色省电，具体数据见 [颜色表](measurements.md#显示颜色)。

## 触摸：CST9220

| 模式 | 设置 | 唤醒影响 |
| --- | --- | --- |
| 正常扫描 | 保持触摸芯片供电，INT 接入 MCU 唤醒源 | 用于触摸唤醒 |
| TP 休眠 | 驱动支持 `D1 05`；`D1 09` 恢复 | 尚未确认休眠后可用触摸唤醒 |
| 低速扫描 | 无已确认命令，需供应商提供 | 不能套其他 CST 型号寄存器 |

放慢 MCU 的 I²C 轮询只减少读取，不改变 TP 内部扫描频率。需要低速扫描时确认扫描周期、INT 电平/锁存/清除和退出指令。

## Wi-Fi

| 需求 | 设置 |
| --- | --- |
| 保持联网并省电 | Wi-Fi 初始化后调用 `esp_wifi_set_ps(WIFI_PS_MIN_MODEM)`，检查返回值 |
| 手动 light sleep，不保连接 | 睡前 `esp_wifi_stop()`，醒后 `esp_wifi_start()` 并等待重新连接 |
| 自动 light sleep 保连接 | 启用 tickless idle、自动睡眠及 modem sleep；核对当前 Wi-Fi 驱动支持 |
| 完全禁用 | 不初始化 Wi-Fi；仅断开 AP 不等于停用驱动 |

## USB

保留 USB 唤醒的路径：完成枚举 → 主机允许总线挂起、暂停活跃通信 → MCU light sleep → 主机恢复总线 → 重建 Iris 会话。
主机持续通信或禁止挂起时，不能按这条路径进入硬件睡眠。Gateway 自动空闲释放/按需重连尚未接入；不修改系统电源策略或停止其他客户端来强行进入睡眠。
USB 恢复通信与屏幕恢复分开检查；睡眠期间保屏恢复仍有未解决的黑屏问题。插充电器、插拔线及 USB Serial/JTAG 不按此路径推断。
