# 功耗数据速查

适用 ESP32-S31 ESP-Mosaico、CO5300 OLED、CST9220。下表是已有整板电流记录，**不是各芯片独立电流**。供电电压、USB/充电状态和采样窗口未全部记录，不能跨表相减拆算模块功耗。

## 各模式与模块

| 模式 / 模块 | 条件 | 电流 |
| --- | --- | ---: |
| ESP + 整板，固定 320 MHz | 停动画，面板 80% | 102 mA |
| ESP + 整板，DFS 下限 160 MHz | 停动画，面板 80% | 85 mA |
| ESP + 整板，DFS 下限 40 MHz | 停动画，面板 80% | 72 mA |
| ESP + 整板，DFS 下限 40 MHz | 停动画，面板 20% | 66 mA |
| ESP + 整板，DFS 下限 40 MHz | 拔屏，显示外设未确认停用 | 51 mA |
| ESP + 整板，DFS 下限 20 MHz 实验 | 面板 80%，与测流同步的驻留记录不足 | 70 mA |
| Light sleep + 整板 | 拔屏，其他条件未完整记录 | 2.98 mA |
| Light sleep + 整板 | 保留显示，其他条件未完整记录 | 12.3 mA |
| Light sleep + 整板 | 白色大卡片 / 夜间主题，亮度未记录 | 34 / 14 mA |
| AOD + 整板 | 20% 面板亮度；MCU 状态、供电条件不完整 | 约 10 mA，待复核 |
| Deep sleep | 无可用的同条件记录 | 未测 |
| ESP 芯片单独 | 未隔离供电测量 | 未测 |
| 显示模组单独 | 未隔离供电测量 | 未测 |
| CST9220 正常 / 低速扫描 / 休眠 | 无独立测量，低速扫描命令未确认 | 未测 |
| Wi-Fi / USB 单独 | 无独立测量 | 未测 |

DFS 表各档 Wi-Fi 开启并使用 modem sleep。夜间主题同时更改颜色、动画及软件压暗，不能把差值全部归到背景。AOD 约 10 mA 来自“12-10mA”的反馈，未确认完整测量条件，不作为确定收益。
