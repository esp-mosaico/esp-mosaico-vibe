# ESP-Mosaico UI 设计建议

本文是建议，不是强制显示要求。应用可以不采用下列圆角；验收不以是否画出半径 60 的控件为准。

## 面板

实物屏是 480×480，四角大约 60px 会被面板裁掉。帧缓冲仍是方形 RGB565，设备和 Host 都按 480×480 整幅绘制。

## 预览

Host `game sim` 网页可以把可视区域裁成圆角 60px，用来对照真机上看不到的四角。这只是预览参考，不要求游戏、GSP 页面或控件自己画出同样的圆角框。

## 布局

建议把关键文字、状态和触控留在四角裁切内侧。贴边的强调框如果要用圆角，可以按半径 60 来估。按钮、HUD、卡片继续用各自合适的圆角或直角即可。
