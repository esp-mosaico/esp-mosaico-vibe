# Simulator evidence

`flow-state.json` is generated by the shared-C `game_flows` executable. It
records the terminal states reached by the repeatable PvE and development-PvP
scenarios. Visual captures generated from the native GSP simulator are stored
alongside it.

The `native_pve_*` captures cover selection, legal hints, AI reply,
resignation and settlement. The
`native_pvp_*` captures cover pairing/start, disconnect, synchronization
failure, reconnect, draw request and agreed-draw settlement.
`native_promotion_*` covers the mandatory four-choice panel and a knight
promotion that immediately reaches insufficient-material draw.

Regenerate with `tests/run_sim_replay.py`; use `--promotion-only` together
with the Host-only `MOSAICO_GAME_SIM_FEN` startup seam for the promotion
scenario.
